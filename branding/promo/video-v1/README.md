# Sky Grid promo video v1

An 11-second, 1080×1920 vertical social video built around the desired outcome rather
than an explanation of the buddy blur mechanic.

## Creative sequence

1. **Hook:** `WHAT IF EVERY MORNING BECAME THIS?` over a labelled concept Sky Grid visual.
2. **Proof:** the real Today screen and `ONE SKY. EVERY MORNING.`
3. **Social reason:** `DO IT WITH ONE FRIEND.` over an explicitly labelled AI lifestyle image.
4. **Payoff:** the real Sky Grid screen and `A YEAR OF MORNING SKIES.`
5. **Share + download CTA:** `SEND THIS TO YOUR MORNING PERSON.` / `DOWNLOAD SKY GRID`.

The lifestyle image was generated with OpenAI's built-in image generation tool. Turn
on TikTok's **AI-generated content** label when posting; the frame itself also says
`AI-GENERATED IMAGERY`.
